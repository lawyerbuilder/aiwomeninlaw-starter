# How to write a session log

- type: guide
- date: 2026-10-05
- related: [[MEMORY]], [[decisions/README]]

Write one log at the end of each working session, in this folder. Name the file with the date, for example `2026-10-17.md`. If there are two sessions on one day, add a letter: `2026-10-17b.md`. Then add one line for it to the Sessions section of [[MEMORY]]. Fictional data only.

## Template

Copy everything inside the box into the new log.

```text
# Session 2026-10-17

- type: session
- date: 2026-10-17
- related: [[decisions/2026-10-17-sort-by-due-date]], [[redesign]]

## What was done
- Built the request list page with fictional requests.

## What changed
- Files: request-list.html (new).
- Notes: [[redesign]] updated; new decision [[decisions/2026-10-17-sort-by-due-date]].

## Open questions
- Should overdue requests show in red? Ask the team (fictional).

## What is next
- Add the form for a new request.
```
