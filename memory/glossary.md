## Course terms

- CLAUDE.md - the standing instructions Claude Code reads at the start of every session in this folder.
- memory folder - the notes in this folder, which Claude reads and updates so that decisions are written down between sessions.
- index - [[MEMORY]], the list of every note with a one-line summary.
- link - a reference to another note, written with double square brackets around the note name.
- decision note - a short note recording one decision, its reason and its date. See [[decisions/README]].
- session log - a short note recording what was done in one working session. See [[sessions/README]].
- commit - a saved version of the project, recorded by Git.
- push - sending saved versions from your computer to GitHub.
